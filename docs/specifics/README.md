# Folder Panduan Spesifik (Specific Implementation Guidelines)

Folder ini berisi panduan teknis mendalam dan spesifik yang ditujukan untuk pengembang maupun pemilik lembaga yang ingin mempelajari, mengelola, atau membangun ulang aplikasi **Daely Report Studio** dari awal.

## Daftar Dokumen Panduan:

1. 📖 **[GUIDELINE_IMPLEMENTASI_DARI_NOL.md](./GUIDELINE_IMPLEMENTASI_DARI_NOL.md)**
   - Panduan lengkap implementasi dari nol: Setup Supabase, eksekusi `schema.sql`, konfigurasi RLS & Storage, setup akun admin pertama via `app_metadata`, alur whitelist pengajar, konfigurasi `.env.local`, hingga deployment ke Vercel.

2. 🎨 **[WHITE_LABEL_GUIDE.md](../WHITE_LABEL_GUIDE.md)**
   - Panduan kustomisasi identitas merek, logo lembaga, nama aplikasi, warna tema, dan penggantian aset visual.

3. 🛡️ **[AUDIT_WORKFLOW_DAN_KEAMANAN_SISTEM.md](../AUDIT_WORKFLOW_DAN_KEAMANAN_SISTEM.md)**
   - Laporan audit lengkap mengenai arsitektur otentikasi whitelist (Opsi 2), bukti pengujian eskalasi hak akses admin, dan matriks keamanan database.
